# West Rand Judo Association Website

React project scaffold for the WRJA website (INSY7315 WIL module).

This is currently interface-only — no backend, no auth, no database.
All content is placeholder text/images so the pages can be reviewed and
adjusted before any functionality is wired up.

## Setup (PowerShell)

```powershell
npm install
```

## Run locally

```powershell
npm run dev
```

## Build

```powershell
npm run build
```

## Folder structure

```
src/
├── components/     NavigationBar, SiteFooter, EventCard, GalleryItem, NewsPost, Reveal, and the Home page sections
├── pages/          HomePage, AboutPage, EventsPage, ProgramsPage, GalleryPage, NewsPage, ContactPage, LoginPage, SignupPage, AdminPage
├── hooks/          useScrollReveal.js — scroll-in animation hook
├── styles.css
├── App.jsx
└── main.jsx
```

## Naming convention

Full, direct, descriptive names throughout — no abbreviations. Pages end in `Page`.
